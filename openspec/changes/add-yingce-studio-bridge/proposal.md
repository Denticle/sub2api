## Why

工作台目前只有无限画布（纯前端，内嵌在主站）。用户需要一个完整的 AI 视频与短剧工作台：小说到成片的流水线、角色与分镜管理、画布 Agent、图片与视频工作台。开源项目「影策」（open-ai-canvas，MIT，v1.7.3.4）具备这些能力，并且是认真做过安全的多用户服务。

影策自带账号、积分、充值、支付和渠道管理，与 forapi 大面积重叠，界面上也带着它自己的品牌、作者信息和若干第三方服务。本变更把它作为 forapi 的「视频工作台」独立部署：

- **身份**交给 forapi：主站顶部菜单点「视频工作台」，新标签页打开并自动登录，不需要再输入密码。
- **模型调用与计费**交给 forapi：每一次生成都用这个用户自己的 forapi 密钥，费用记在 forapi 的同一个余额里。
- **外观**与主站统一：forapi 的 logo、品牌名、配色。
- **第三方内容**移除：作者与赞助信息、外部服务目录、第三方登录、在线更新、第三方 CDN 资源。TapNow / LibTV 画布导入属于创作功能，保留。
- **可持续同步上游**：改动优先走影策自带的后台配置，必须改代码的部分做成锚点校验的补丁，每次从干净的上游源码重建。

视频工作台**不内嵌**到 forapi 主站，是一个独立站点。

## What Changes

**forapi（sub2api）：**

- 新增一个最小 OAuth 2.0 授权服务器（授权码 + PKCE S256），只服务一个预先配置的客户端（视频工作台）。
- 新增授权页：已登录直接确认；首次授权显示一次确认，之后自动通过。
- 新增 `/oauth/token`、`/oauth/userinfo`，以及仅服务端可调用的「工作台专用密钥」接口。
- 首次授权时为用户创建（或复用）一把「视频工作台专用」API Key，用户在「API 密钥」页可见、可停用、可重置。
- 管理后台新增视频工作台接入配置：开关、Client ID / Secret、回调地址、专用密钥默认分组与额度。
- **顶部菜单**新增「视频工作台」（主站顶栏与首页导航），新标签页打开，直接进入自动登录流程。侧栏不增加入口。

**视频工作台（影策，独立部署于子域）：**

- 品牌、logo、配色、SEO、页脚、登录页背景全部用影策自带的**外观设置**配置成 forapi，不改源码。
- 登录：复用影策已有的通用 OAuth 登录，指向 forapi；隐藏并在后端拒绝密码注册与登录（管理员除外）。
- 计费：关闭影策积分，不扣积分、不显示钱包与充值。
- 每用户密钥：在影策注入系统渠道密钥的唯一位置，改为注入当前任务所属用户的 forapi 专用密钥。
- 第三方移除：能用开关和环境变量关的用配置关；剩下的（欢迎页贡献者与赞助、硬编码的作者署名、默认外链视频、第三方 CDN 模型）用补丁移除或换成本地资源。

## Capabilities

### New Capabilities

- `oauth-provider`：forapi 作为 OAuth 2.0 授权服务器，为单一受信任客户端签发授权码与访问令牌，提供 userinfo。
- `studio-bridge-key`：为视频工作台用户托管一把专用 API Key，仅服务端可取回，用户可查看、停用、重置。
- `video-studio`：视频工作台的部署、品牌统一、登录桥接、积分关闭、每用户密钥注入、第三方移除与上游同步流程。

### Modified Capabilities

- 主站顶部导航（`AppHeader`）与首页导航新增「视频工作台」一项；不改变现有入口行为。

## Impact

- **sub2api 后端**：新增 `internal/oauthprovider/` 与 `/oauth/*` 路由；两张表（授权码、访问令牌，只存哈希）；API Key 增加用途标记。复用现有 JWT 会话、APIKeyService、SettingRepository、SecretEncryptor、限流。
- **sub2api 前端**：授权确认页、管理后台一个设置分区、顶栏一项。
- **视频工作台**：新增 `video-studio-integration/` 目录（补丁、覆盖文件、品牌资源、配置脚本、构建脚本），结构同 `canvas-integration/`。
- **部署**：独立容器栈与一个 nginx server 块；证书走现有 certbot；不改 new-api、sub2api 现有容器与数据库。
- **资源**：本机 62 GB 内存，当前约 7 GB 使用；视频工作台整栈预计 1–2 GB 常驻。
- **许可**：MIT 只要求在软件副本中保留版权与许可声明。镜像内保留上游 `LICENSE` / `NOTICE` 文件；界面上不展示上游品牌与作者。
